Source files for baby names. This book uses the Scotland baby names file, full-list-1974-2023.csv. I have also included files from the social security website, which include a Michigan-specific and some year-specific national lists. The csv format is different for each type, so I included the header line (if it exists) and the first line of data. This program needs to be modified to use the Michigan or national files.
